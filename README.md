# Kalendasom

Kalendasom is a beautiful and performant calendar application.

## Backend

Kalendasom uses [Clepsydre](https://gitlab.gnome.org/TitouanReal/clepsydre), which makes it backend-agnostic. The application currently uses the [ccmd](https://gitlab.gnome.org/TitouanReal/ccmd) backend, but a one-line change is enough to uses another backend, provided there is a Clepsydre implementation.

## How to run

Start the ccmd backend, grab the Kalendasom Flatpak and run it.
